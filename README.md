# TRACE

Jeu de rôle solo pour macOS. Vous écrivez ce que fait votre personnage ; un
maître du jeu vous répond, lance les dés et fait vivre le monde autour de vous.

**Page de présentation et de téléchargement : <https://vlefils.github.io/trace-releases/>**

## Télécharger

Les paquets sont dans les [versions publiées](https://github.com/vlefils/trace-releases/releases/latest) :

- `TRACE-macOS-arm64.dmg` pour les Mac à puce Apple (M1 et suivantes) ;
- `TRACE-macOS-x86_64.dmg` pour les Mac à processeur Intel.

## Ce qu'il faut

- macOS 15 ou plus récent ;
- Codex CLI installé et connecté à votre compte : le maître du jeu et les
  illustrations passent par lui ;
- une connexion Internet pendant le jeu.

Le guide d'installation, à la main ou avec un prompt à donner à un agent de code,
se trouve sur la page.

## Ce dépôt

Il contient uniquement la page (`index.html`, `styles.css`, `app.js`, `assets/`)
et les paquets publiés. L'application n'est pas encore notarisée par Apple : au
premier lancement, macOS demande une autorisation, expliquée dans le guide.
